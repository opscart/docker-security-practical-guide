## Hypothesis

If supply chain gates do not run before runtime admission, then runtime enforcement absorbs failures that should have been caught at build time. This experiment validates the supply chain layer using build-time policy gates in GitHub Actions and Azure DevOps that produce the attestations consumed by E2 and enforced by E3.
